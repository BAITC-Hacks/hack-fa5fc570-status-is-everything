# Weather Forecast

WindMind AI использует погодный прогноз для координат каждой ветряной турбины, чтобы рассчитать будущую генерацию электроэнергии на 24–48 часов.

Основные погодные параметры:

- Wind Speed — скорость ветра
- Wind Direction — направление ветра
- Wind Gusts — порывы ветра
- Temperature — температура
- Pressure — атмосферное давление
- Humidity — влажность

## Как это работает

Coordinates → Weather Forecast → Physics Features → ML Model → Generation Forecast → Risks

Погодные данные обрабатываются системой и передаются в ML-модель, которая рассчитывает почасовой прогноз генерации отдельно для каждой турбины и для всего ветропарка.

В интерфейсе планируется отдельный **Weather Forecast** блок с прогнозом погоды на следующие 48 часов и графиком изменения скорости ветра.
