# 🚀 WindMind AI — Demo Guide

Этот файл содержит короткий сценарий демонстрации проекта для жюри HackAlem AI.

## 1. Запуск системы

Запустите приложение командой:

`streamlit run app.py`

После запуска откроется интерфейс WindMind AI.

## 2. Выбор прогноза

Выберите дату из тестового периода февраля 2026 года и установите горизонт прогнозирования:

- 24 часа
- 48 часов

После этого запустите цикл прогнозирования.

## 3. Результат

Система показывает:

- прогноз генерации Turbine 1;
- прогноз генерации Turbine 2;
- суммарный прогноз кластера;
- почасовой график генерации;
- диапазон неопределённости;
- предупреждения о возможных рисках.

## 4. Agent Execution Trace

Во время выполнения можно проследить основные этапы работы системы:

Weather Data → Data Processing → Physics Features → ML Forecast → Risk Analysis → Final Forecast

Это позволяет увидеть не только конечный результат, но и последовательность работы Agentic AI.

## 5. Weather Update

Для демонстрации автоматического пересчёта измените погодные входные данные через функцию симуляции обновления погоды.

После обновления WindMind AI повторно запускает расчёт и показывает новый прогноз генерации.

## 6. Что показать жюри

Рекомендуемый порядок демонстрации:

1. Выбрать дату.
2. Запустить прогноз на 48 часов.
3. Показать общий график генерации.
4. Показать прогнозы двух турбин.
5. Показать предупреждения системы.
6. Показать Agent Execution Trace.
7. Запустить обновление погоды.
8. Показать, как изменился прогноз.

Таким образом, за несколько минут можно продемонстрировать полный цикл работы WindMind AI.
