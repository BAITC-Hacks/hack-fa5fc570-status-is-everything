# Инструкции для команды

Актуальное описание — README.md. Старые утверждения о полностью проверенном прогнозе, мощности 2.5 МВт, экономии и доступности погодного архива больше не действуют.

Сохраните исходные CSV. Настройки и соответствие турбин — config/settings.json.
Подготовка и обучение: python -m src.train. Проверка: python -m unittest discover -s tests -v.

Погодному участнику: реализовать источник по config/WEATHER_INPUT.md.
Не подставлять фактическую погоду/реанализ, не выдумывать available_at; явно переводить ветер в м/с.
Для февраля нужны выпуски, доступные на каждый момент расчёта. Для последних 48-часовых окон нужны мартовские часы.
Подтвердить шкалу нормализации, высоту SCADA-ветра и географическую привязку до подключения провайдера.

Интерфейс модели: src.predict.predict_power(weather_dataframe).
Координатор: WindFarmAgent.execute_agent_cycle(as_of_date, horizon_hours=48).
Его результат — отдельные строки по турбинам с predicted_power; единицы нормализованные, не МВт.
Прежние совместимые по названию модули data_loader/model делегируют новому конвейеру; прежние структуры результата намеренно изменены, чтобы не выдавать ошибочные физические единицы.

Streamlit и CLI наблюдают за подготовленным источником; внешняя загрузка погоды — отдельный ещё не подключённый адаптер.
